# ADR-001: Initial Technology Stack

- Status: Accepted
- Date: 2026-10-01

## Context

FitFlow requires a mobile frontend, a REST API, persistent storage, real-time services, authentication, caching, and AI capabilities.

## Decision

Use React Native with TypeScript for the frontend, Node.js with Express for the backend, PostgreSQL for persistent storage, Firebase for real-time services and authentication, Redis for caching, and TensorFlow Lite with cloud AI services for AI functionality.

## Consequences

The system is divided into independently maintainable frontend, backend, and AI service components, supported by shared architecture documentation.
